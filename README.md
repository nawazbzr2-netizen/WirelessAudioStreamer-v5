# Wireless Audio Streamer v5

Android app for wireless system audio streaming, camera, screen cast and remote control over WiFi / Hotspot / Bluetooth.

## Features
- One-touch system audio streaming between phones
- Camera streaming & preview
- Screen casting
- Remote control via Accessibility Service
- WiFi / Hotspot discovery and Bluetooth signaling
- Adaptive / low-latency audio (ADPCM)

## Build
Open in Android Studio or use GitHub Actions to build the release APK.

```bash
gradle assembleRelease
```
